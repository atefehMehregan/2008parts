# نشان برندها — public/img/brands/

بخش «برندها» در پایین صفحهٔ اصلی نشانِ هر برند را از همین پوشه برمی‌دارد.

## نام فایل

نام فایل باید **اسلاگ برند** باشد، همان که در نشانی `/brand/<slug>` هم
می‌آید. سرویس `src/services/brandLogos.js` پوشه را می‌خواند و بر اساس
همین نام، نشان را به برند می‌چسباند.

پسوندهای پذیرفته‌شده، به ترتیب اولویت: `.svg` `.webp` `.png` `.jpg`

اسلاگ برندهای فعلی:

| برند | نام فایل |
|---|---|
| بوش | `بوش.svg` |
| توتال | `توتال.svg` |
| دپو | `دپو.svg` |
| مان | `مان.svg` |
| موپار | `موپار.svg` |
| پژو سیتروئن | `پژو-سیتروئن.svg` |
| یوروریپار | `یوروریپار.svg` |

اسلاگ دقیق هر برند را از بخش مدیر یا از نشانی `/brand/...` بگیرید.

## تا وقتی فایلی نیست

برندی که فایل نشان ندارد، به‌جای تصویر یک کاشیِ نامِ طراحی‌شده نشان
داده می‌شود — نه جای خالی و نه تصویر شکسته. به‌محض اینکه فایل را
اینجا بگذارید و سرور را دوباره راه بیندازید، تصویر جای کاشی را می‌گیرد.

## ⚠️ حقوق

نشان خودروسازها و سازندگان قطعه **علامت تجاری ثبت‌شده** است. فقط
فایلی را اینجا بگذارید که اجازهٔ استفاده از آن را دارید. در این مخزن
هیچ نشانِ شخص ثالثی کشیده یا دانلود نشده است.
